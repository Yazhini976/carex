# CAREX Requirements

## Core HCL use case
Patients can browse specialties and doctors, view availability, and book appointments.

## Required workflow
- Online and offline consultation modes
- Different doctors for online and offline appointments
- Appointment status: completed, cancelled, no-show
- Daily summaries by mode and specialty
- Secure APIs with authentication, authorization and rate limiting

## Stretch direction
- Email confirmation
- Automated reminders
- Admin dashboard
