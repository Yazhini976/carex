# CAREX Demo Flow

1. Patient logs in.
2. Patient enters a healthcare need in natural language.
3. CAREX recommends a suitable specialty (non-diagnostic).
4. CAREX recommends doctors based on mode and availability.
5. Patient books a slot.
6. System displays estimated waiting time.
7. Demonstrate cancellation and smart waitlist.
8. Admin views workload intelligence.
9. Admin runs a doctor-unavailability simulation.
10. Demonstrate authorization with an invalid role/API access.
