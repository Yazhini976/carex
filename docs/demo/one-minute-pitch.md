# CAREX — One-Minute Elevator Pitch

**Target Duration:** 55–60 seconds  
**Tone:** Confident, professional, healthcare-tech focused

---

### Spoken Script

> "Good morning, judges. In modern healthcare, booking an appointment is easy—but navigating care is broken. Patients don't know which specialist they need, waiting rooms are unpredictably congested, and when a doctor calls in sick, administrative chaos takes over.
>
> We built **CAREX: The Intelligent Doctor Appointment and Patient Flow Management System**.
>
> CAREX transforms scheduling from a simple transactional calendar into an intelligent operational platform. 
>
> For patients, it provides non-diagnostic **Smart Consultation** navigation, **Explainable Doctor Matching** with multi-factor scoring, dynamic wait-time estimation, and an automated **Smart Waitlist** that backfills cancellations.
>
> For healthcare administrators, our standout innovation is the **What-If Scheduling Simulator** and **Workload Intelligence Engine**—allowing clinics to model provider absences, predict queue spillover, and rebalance appointments before disruption happens—all with zero risk to production data.
>
> Built with **Spring Boot 3, React 18, and PostgreSQL 17**, secured by **Stateless JWT and granular RBAC**, CAREX helps clinics: **Book smarter, wait less, and manage better.**
>
> Thank you!"

---

### Core Delivery Points
* **Problem**: Triage confusion, wait time uncertainty, scheduling fragility.
* **Solution**: CAREX intelligent patient flow platform.
* **Key Innovation**: Explainable matching + What-If disruption simulation.
* **Architecture**: Spring Boot + React + PostgreSQL + JWT RBAC.
* **Tagline**: Book smarter. Wait less. Manage better.
